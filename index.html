잠금 해제

PIN을 입력하세요.

PIN은 그대로 저장되지 않고, 임의 salt와 PBKDF2로 계산한 검증값만 이 기기에 저장됩니다. Chrome이 비밀번호 저장을 제안하면 거절해도 됩니다.

이 환경에서는 Web Crypto API를 사용할 수 없어 PIN을 확인할 수 없습니다. HTTPS 주소(예: GitHub Pages, Render)로 다시 열어 주세요.

이 잠금이 보호하는 범위
  • 이 잠금은 같은 기기를 잠깐 함께 보는 사람이 화면과 즐겨찾기를 바로 보지 못하게 하는 가벼운 화면 잠금입니다.
  • 강력한 계정 인증이 아닙니다. 짧은 숫자 PIN은 저장소에 접근할 수 있는 사람이 컴퓨터로 짧은 시간에 모두 시도해 볼 수 있습니다.
  • 소스 코드 변경, 개발자 도구를 통한 브라우저 저장소 접근, 사이트 데이터 삭제로 우회되거나 초기화될 수 있습니다.
  • Chrome 방문 기록, Google 계정 활동, 학교 기기 관리 및 네트워크 기록에는 아무런 영향을 주지 않습니다.

    보안 및 저장 정책

    이 앱이 하는 일

    • 방문한 주소, 검색어, 방문 시간, 페이지 제목을 자동으로 저장하지 않습니다.
    • 현재 주소는 보는 동안에만 메모리에 있고, 잠금·닫기·초기화 시 지웁니다.
    • 직접 “저장”한 바로가기·즐겨찾기만 이 기기의 브라우저 저장소에 PIN에서 만든 키로 암호화해 저장합니다.
    • 분석 도구, 광고, 추적 코드, 외부 라이브러리를 쓰지 않으며 어떤 서버로도 주소를 보내지 않습니다.

    이 앱이 제어할 수 없는 것

    • Chrome 방문 기록 및 Chrome 동기화
    • Google 계정의 웹 및 앱 활동
    • 학교 기기 관리 정책과 네트워크·필터링 기록
    • 방문한 사이트가 자체적으로 남기는 기록

    이 앱은 위 기록을 지우거나 막거나 숨기지 않으며, 그렇게 할 수도 없습니다.

    화면이 비어 있거나 “연결을 거부했습니다”가 보이나요?
    • 많은 사이트가 보안을 위해 다른 페이지 안(iframe)에 표시되는 것을 막습니다. 브라우저는 이 차단 여부를 이 앱에 알려 주지 않으므로 자동으로 판별할 수 없습니다.
    • 대안 1: 사이트가 제공하는 임베드용 주소가 있는지 확인합니다(예: 동영상의 “퍼가기” 주소).
    • 대안 2: 새 탭 버튼으로 직접 엽니다. 이 경우 일반 탐색과 같으므로 Chrome 방문 기록과 Google 계정 활동에 남을 수 있습니다.
    • 대안 3: 후 원하는 방법으로 엽니다.
    • iframe 제한: 로그인 유지, 팝업, 다운로드, 알림, 일부 결제·동영상 기능이 작동하지 않을 수 있으며, 뒤로/앞으로 이동 버튼이 없습니다. iframe 안의 클릭·입력은 자동 잠금 타이머의 “활동”으로 감지되지 않습니다.
