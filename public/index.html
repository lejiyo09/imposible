QuietSpace

잠금 해제

PIN을 입력하세요.

PIN은 평문 저장되지 않습니다. 임의 salt + PBKDF2 해시 검증값만 저장됩니다.

이 환경에서는 Web Crypto API를 사용할 수 없어 PIN을 확인할 수 없습니다. HTTPS 주소(GitHub Pages, Render 등)로 열어 주세요.

이 잠금이 보호하는 범위
  • 같은 기기를 잠깐 보는 사람이 화면과 즐겨찾기를 바로 보지 못하게 하는 가벼운 화면 잠금입니다.
  • 강력한 계정 인증이 아닙니다. 짧은 숫자 PIN은 기기에 접근할 수 있는 사람이 짧은 시간에 모두 시도할 수 있습니다.
  • 소스 코드 변경, 개발자 도구를 통한 저장소 접근, 사이트 데이터 삭제로 우회·초기화될 수 있습니다.
  • Chrome 방문 기록, Google 계정 활동, 학교 기기 관리·네트워크 기록에는 아무런 영향을 주지 않습니다.

    보안 및 저장 정책

    이 앱이 하는 일

    • 방문한 주소, 검색어, 방문 시간, 페이지 제목을 자동으로 저장하지 않습니다.
    • iframe 안에서 본 사이트는 Chrome 방문 기록에 나타나지 않습니다. Chrome 기록에는 QuietSpace 페이지 주소만 남습니다.
    • 모든 사이트는 QuietSpace 서버(Render)를 거치는 프록시(Ultraviolet)로 iframe 안에서 열립니다. 따라서 방문하는 사이트와의 통신은 이 서버를 지나갑니다. 서버는 주소를 기록하지 않습니다.
    • 사이트를 보는 동안 사이트가 남기는 쿠키·저장 데이터는 이 기기에 임시로 생기며, 닫기·잠금·앱 시작 시 지웁니다.
    • 직접 "저장"한 항목만 이 기기 저장소에 AES-GCM으로 암호화해 보관합니다.
    • 분석·광고·추적 코드를 쓰지 않습니다.

    이 앱이 제어할 수 없는 것

    • Chrome 방문 기록 — iframe 내 탐색은 기록되지 않으나, "새 탭"으로 연 사이트는 Chrome 기록에 남습니다
    • Google 계정의 웹 및 앱 활동 (Google에 로그인 상태라면 서버 측 활동 기록이 남을 수 있음)
    • 학교 기기 관리 정책·네트워크·필터링 기록
    • 방문한 사이트가 자체적으로 남기는 기록

    위 항목은 앱 밖의 시스템이므로 이 앱이 지우거나 차단할 수 없습니다.
