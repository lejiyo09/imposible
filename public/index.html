    보안 및 저장 정책

    이 앱이 하는 일

    • 방문한 주소, 검색어, 방문 시간, 페이지 제목을 자동으로 저장하지 않습니다.
    • iframe 안에서 본 사이트는 Chrome 방문 기록에 나타나지 않습니다. Chrome 기록에는 Geo-Zebra 페이지 주소만 남습니다.
    • 모든 사이트는 Geo-Zebra 서버(Render)를 거치는 프록시(Ultraviolet)로 iframe 안에서 열립니다. 따라서 방문하는 사이트와의 통신은 이 서버를 지나갑니다. 서버는 주소를 기록하지 않습니다.
    • 사이트가 남기는 저장 데이터는 닫기·잠금·앱 시작 시 지웁니다. 단, "사이트 로그인 유지"(설정, 기본 켜짐)가 켜져 있으면 로그인 쿠키는 남깁니다.
    • 직접 "저장"한 항목만 이 기기 저장소에 AES-GCM으로 암호화해 보관합니다.
    • 분석·광고·추적 코드를 쓰지 않습니다.

    이 앱이 제어할 수 없는 것

    • Chrome 방문 기록 — 앱 안의 탭에서 본 사이트는 기록되지 않으나, "Chrome 새 탭에서 열기"로 연 사이트는 Chrome 기록에 남습니다
    • Google 계정의 웹 및 앱 활동 (Google에 로그인 상태라면 서버 측 활동 기록이 남을 수 있음)
    • 학교 기기 관리 정책·네트워크·필터링 기록
    • 방문한 사이트가 자체적으로 남기는 기록

    위 항목은 앱 밖의 시스템이므로 이 앱이 지우거나 차단할 수 없습니다.

    보안상 한계
    
        
      
          
    • PIN 잠금은 화면 가림용 가벼운 보호이며 계정 인증이 아닙니다.
      • 
          
    • PIN은 모든 기기에서 같은 값으로 고정되어 있고, 그 검증값(PBKDF2 해시)이 앱 코드에 들어 있습니다. 6자리 숫자는 경우의 수가 적어, 코드를 본 사람은 컴퓨터로 모든 숫자를 대입해 PIN을 알아낼 수 있습니다.
      • 
          
    • 잠금은 이 화면에서만 동작합니다. 서버 주소를 아는 사람이 개발자 도구로 화면을 우회하면 프록시는 PIN 없이 쓸 수 있습니다.
      • 
          
    • 코드 변경, 개발자 도구, 확장 프로그램, 사이트 데이터 삭제로 우회·초기화 가능합니다.

    • 프록시로 연 사이트의 스크립트는 이 앱과 같은 출처에서 실행됩니다. 악의적인 사이트라면 이 기기에 저장된 암호화된 즐겨찾기와 PIN 검증값을 읽어 갈 수 있으니, 믿을 수 있는 사이트만 여세요.

    • Chrome 기록, Google 계정 활동, 학교 관리 기록에는 영향을 주지 않습니다.
